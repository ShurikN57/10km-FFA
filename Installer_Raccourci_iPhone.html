Importer vers Comparateur — v2.9

À faire

  1. Dans ton raccourci, supprime l’action Ouvrir.
  2. Garde seulement Exécuter JavaScript sur la page web.
  3. Remplace l’ancien script par celui-ci.
  4. Garde Afficher dans la feuille de partage activé.

Ensuite : Safari → UTMB ou GoTiming → Partager → Importer vers Comparateur.
