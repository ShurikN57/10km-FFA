Importer vers Comparateur — v3.0

Configuration du raccourci

  1. Première action : Exécuter JavaScript sur la page web.
  2. Colle le script v3.0 ci-dessus.
  3. Deuxième action : Si le Résultat JavaScript commence par ERROR:, affiche-le avec Afficher l’alerte.
  4. Sinon : Ouvrir les URL avec Résultat JavaScript.

Le raccourci doit rester visible dans la feuille de partage de Safari.

Utilisation : Safari → UTMB ou GoTiming → Partager → Importer vers Comparateur.
