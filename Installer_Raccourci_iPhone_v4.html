Importer vers Comparateur — v4 (sans presse-papiers)

Pourquoi ce changement

L'ancienne version passait par le presse-papiers iOS (copier le résultat, puis le relire dans Safari). C'est le maillon le plus fragile de Safari sur iPhone : la demande de permission peut rester bloquée sans jamais afficher d'erreur, ce qui donnait l'impression que « rien ne se passe ».

La v4 construit directement une URL contenant les données (encodées) et l'ouvre — le comparateur lit ces données depuis l'URL elle-même, sans jamais toucher au presse-papiers. Le script GoTiming essaie aussi en priorité de lire le vrai tableau HTML de la page (plus fiable), et ne retombe sur l'ancien scan du texte visible qu'en dernier recours.

Nouveau raccourci — seulement 3 étapes

  1. Recevoir la page depuis la Feuille partagée (comme avant).
  2. Exécuter JavaScript sur la page web → colle le script v4 ci-dessus (remplace l'ancien script en entier).
  3. Ouvrir les URL → mets la variable Résultat JavaScript (PAS une URL fixe cette fois).

Supprime les étapes « Copier dans le presse-papiers » et « Ouvrir les URL » vers l'adresse fixe — elles ne sont plus nécessaires. Le script produit lui-même l'URL finale (vers app_base.html#import64=...) et Safari s'ouvre directement dessus, déjà rempli.

Limite à connaître : pour une course avec plusieurs centaines de participants, l'URL générée peut devenir longue (dizaines de milliers de caractères). Ça reste dans les limites de Safari/Raccourcis pour la plupart des courses locales, mais si un jour ça coince sur une très grosse course (1000+ participants), dis-le moi et j'ajouterai un découpage en plusieurs morceaux.
