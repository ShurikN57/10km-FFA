Ce que fait cette version

  • Lit directement les 6 scans enregistrés dans IndexedDB : 2024/2025/2026 × M/F.
  • Produit un seul fichier final au format de ffa_base.json.
  • Conserve le meilleur chrono trouvé sur les trois années.
  • Fusionne automatiquement les lignes portant le même ID FFA.
  • Fusionne les lignes sans ID avec un profil ID si nom normalisé + année + sexe concordent.
  • Si l'année manque, rattache seulement lorsqu'il existe un unique candidat ID avec le même nom + sexe.
  • Ne fusionne jamais automatiquement deux IDs FFA distincts.
  • Génère aussi un fichier AUDIT avec les cas ambigus et les conflits d'ID.
